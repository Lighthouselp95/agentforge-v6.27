# REACT TYPESCRIPT SCALE - Full Course
## Xây Web App Server-Side Dễ Scale - Từ Zero đến Production

**Stack:** React 19 + TypeScript 5.5 + Next.js 15 (App Router) + Vite + Tailwind + Prisma + Turborepo
**Mục tiêu:** Học xong tự build + deploy app chịu được 1M user, dễ mở rộng team.

**Yêu cầu đầu vào:** Biết JS cơ bản (biến, hàm, async/await).
**Lộ trình:** 4 tuần - mỗi chương 2-3 giờ học + code.
